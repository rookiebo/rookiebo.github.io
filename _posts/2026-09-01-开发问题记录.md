## 问题记录

### Bug现象

1. 初始化过程中若切换到其它程序容易出现初始化结束后对话框不显示的问题
2. 初始化结束，`HardwareManager.ErrorMsg` 有内容
3. 使用`Dispatcher.CheckAccess()`为 true（在 UI 线程）
4. `dialogService.ShowDialog()`会执行，但对话框不显示
5. 主窗口仍活跃，进度条的动画还是运动状态

### 问题代码

```csharp
async void ExecuteLoadedCommand()
{
    await Task.Run(InitSystem);

    if (string.IsNullOrEmpty(HardwareManager.ErrorMsg))
        // 事件聚合器发进入通知
    else
    {
        // 弹出对话框告知初始化失败，哪些部分失败
        dialogService.ShowDialog(DialogNames.AlertDialog, new DialogParameters { { "message", $"初始化存在以下问题\n{HardwareManager.ErrorMsg}" } }, r =>
        {
            if (r.Result == ButtonResult.Yes)
            {
                // 事件聚合器发进入通知
            }
            else
            {
                // 事件聚合器发退出通知
            }
        });
    }
}

private void InitSystem()
{
    Progress = 0; // 初始化进度
    Task<bool> loadConfig = Task.Run<bool>(LoadConfig); // 读取配置文件
    Progress = 6; // 更新进度
    HardwareManager.Init(); // 初始化硬件
    Read();
    Progress = 100; // 完成进度
}
```

```csharp
async public Task Init()
{
    StringBuilder errorMsgBuilder = new StringBuilder();

    InfoMsg = "初始化开始...";

    if (!CommandSender.Init(SystemConfigProvider) || !CommandSender.Connect())
        errorMsgBuilder.AppendLine(CommandSender.InitMessage);
    else
        Thread.Sleep(1000);
    // 执行多个硬件设施的初始化连接
}
```

在`dialogService.ShowDialog()` 前加一行`MessageBox.Show()` 能解决问题，所以猜测原因：

1. 初始化耗时长，用户切换到其它程序，本应用进入后台
2. Windows 限制后台进程抢前台焦点

### 解决方案

#### 方案 A：弹窗前激活主窗口

```csharp
var main = System.Windows.Application.Current.MainWindow;
if (main != null)
{
    if (main.WindowState == WindowState.Minimized)
        main.WindowState = WindowState.Normal;

    main.Activate();
    main.Topmost = true;   // 临时置顶
    main.Topmost = false;
    main.Focus();
}

dialogService.ShowDialog(...);
```

#### 方案B：修改初始化函数的代码

`await Task.Run(InitSystem);`改成`await InitSystem();`
`private void InitSystem()`改成`private async Task InitSystem()`
`HardwareManager.Init();`改成`await Task.Run(() =>HardwareManager.Init());`

最后的代码为：

```csharp
async void ExecuteLoadedCommand()
{
    await InitSystem();

    if (string.IsNullOrEmpty(HardwareManager.ErrorMsg))
        // 事件聚合器发进入通知
    else
    {
        // 弹出对话框告知初始化失败，哪些部分失败
        dialogService.ShowDialog(DialogNames.AlertDialog, new DialogParameters { { "message", $"初始化存在以下问题\n{HardwareManager.ErrorMsg}" } }, r =>
        {
            if (r.Result == ButtonResult.Yes)
            {
                // 事件聚合器发进入通知
            }
            else
            {
                // 事件聚合器发退出通知
            }
        });
    }
}

private async Task InitSystem()
{
    Progress = 0; // 初始化进度
    Task<bool> loadConfig = Task.Run<bool>(LoadConfig); // 读取配置文件
    Progress = 6; // 更新进度
    await Task.Run(() =>HardwareManager.Init()); // 初始化硬件
    Read();
    Progress = 100; // 完成进度
}
```
